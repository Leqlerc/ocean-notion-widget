NOcean Privacy Policy

Last updated September 14, 2026

NOcean is a personal dashboard. Its Google Calendar connection is used only to display calendar events to the person who authorized access.

Google data accessed

NOcean requests read-only access to Google Calendar events. It may process event titles, start and end times, recurrence information, status, and event links from calendars the user has authorized. NOcean cannot create, edit, or delete Google Calendar events.

How data is used

Calendar information is used solely to render the upcoming-events list and calendar inside NOcean. Google user data is not sold, used for advertising, or shared with third parties except infrastructure providers required to operate the application.

Storage and security

The OAuth refresh token is stored server-side in protected deployment environment variables. Short-lived access tokens may be cached temporarily in server memory. Calendar event data is fetched as needed and is not maintained as a separate NOcean database.

Retention and revocation

Access can be revoked at any time from the user's Google Account security settings. Removing the OAuth credentials from the NOcean deployment also ends access.

Google API Services User Data Policy

NOcean's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

For privacy questions, use the support email displayed on NOcean's Google OAuth consent screen.
